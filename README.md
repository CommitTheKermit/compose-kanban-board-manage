>기능 요구 사항<br>
디자인 시안을 참고하여 칸반 보드 프로젝트를 구현한다.
드래그 앤 드롭을 통해 카드 상태를 변경할 수 있게 한다. 

>프로그래밍 요구 사항<br>
여러 번 그려지지 않아도 되는 뷰는 매번 리컴포지션 되지 않아야 한다.
적절한 테스트 방법을 활용하여 기능 요구 사항을 테스트한다.
모든 요구 사항이 테스트 가능하진 않다. 스스로 판단해서 구분한다.
프로젝트 생성을 위한 뷰는 없다. 가짜 데이터와 테스트 더블을 활용한다

## 테스트 목록

#### 단위 테스트
- [x] 새 태스크를 생성했을 때 현재 프로젝트에 삽입되어야 한다
- [ ] 태스크의 상태를 변경 할 수 있어야 한다
 
#### UI 테스트
- [ ] 프로젝트를 선택하면 프로젝트에 저장되어 있는 태스크들이 표시되어야 한다
- [ ] 태스크 드래그 앤 드롭을 통해 상태를 변경 할 수 있어야 한다
- [ ] 드로워에 프로젝트 리스트가 출력되어야 한다
- [ ] 상태를 변경 했을 때 스낵바가 출력되어야 한다

## 기능 목록
 - [ ] 태스크 카드 드래그 앤 드롭
 - [ ] 태스크 카드의 상태가 변경되었을 때 스낵바를 출력해야 한다
 - [ ] 태스크를 프로젝트 별로 관리할 수 있어야 한다

## UI 목록
- [ ] 프로젝트 드로워
  - 드로워 헤더
  - 드로워 설명
  - 프로젝트 컬럼
- [ ] 태스크 상태 변경 스낵바 텍스트
  - "태스크가 이동되었습니다."
